# 💰 Expenso — Modern Expense Tracker

A sleek, lightweight, dark-themed personal finance and expense tracker built with pure HTML5, modern CSS3, and Vanilla JavaScript. Zero dependencies, fully responsive, and works completely offline with local storage persistence.

---

## ✨ Features

- **📊 Live Balance & Totals**: Automatically calculates Total Income, Total Expenses, and Net Balance in real-time.
- **🏷️ Income vs. Expense Categorization**: Color-coded indicators (Teal for Income, Red for Expense) with Indian Rupee (`₹`) formatting.
- **💾 Offline Local Storage**: All entries persist across browser reloads and sessions via `localStorage`.
- **🔍 Quick Filters**: Filter transactions seamlessly by `All`, `Income`, or `Expense`.
- **🗑️ One-Click Delete**: Easily remove individual entries with instantaneous balance recalculation.
- **📱 Responsive & Dark Mode**: Sleek dark UI with ambient radial glows, optimized for desktops, tablets, and mobile screens.
- **⚡ Zero Dependencies**: Pure HTML, CSS, and Vanilla JS — no frameworks or build tools required.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/akshatanand-cell/expense-tracker.git
cd expense-tracker
```

### 2. Run the application
Simply double-click or open `index.html` (or `expense-tracker.html`) in any modern web browser:
```bash
# On Windows (PowerShell)
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```
